1. Introduction

A Wien bridge oscillator is a sinusoidal RC oscillator that uses an op-amp as a non-inverting amplifier and a lead-lag RC network (series RC + parallel RC) as the frequency-selective positive-feedback path. Resistive divider Rf/Rg gives negative feedback that sets the gain.

Principle: at exactly one frequency f0 the RC network gives zero phase shift and an attenuation of 1/3. If the amplifier gain is 3, the loop gain is Aβ = 1 with 0° phase, satisfying the Barkhausen criterion, so a sustained sine wave appears.

Importance: low-distortion audio-range signal generation (Hz to a few hundred kHz), the classic design in audio test generators.

Prerequisites

Non-inverting op-amp gain, RC impedance, complex impedance (s = jω), feedback and Barkhausen criterion.

3. Working Principle

  1. Startup: power-on noise contains all frequencies. The RC network feeds back only a band around f0 in phase.
  2. Growth: with A slightly above 3, Aβ > 1 so the sine amplitude grows exponentially.
  3. Limiting: as amplitude rises, AGC (lamp in Rg, diodes across Rf, or JFET) lowers effective gain to exactly 3, settling the amplitude. Without AGC the op-amp saturates and the output clips.
  4. Steady state: Aβ = 1 at 0° phase; stable sine at f0.

DC behaviour: C₁ blocks DC from the output, R₂ returns the + input to ground, and the non-inverting amplifier amplifies any DC offset by 1 + Rf/Rg (about 3), so the DC offset is small when input bias currents are small. AC behaviour: as analysed in Section 5.

Assumptions: ideal op-amp (infinite input impedance, zero output impedance, flat gain at f0).

Advantages: low distortion, simple, easy tuning with a ganged pot. Limitations: needs AGC, limited by op-amp GBW and slew rate, poor frequency stability compared to crystals.

Common misconceptions: (1) the op-amp does not shift the phase; the feedback network gives 0° at f0. (2) Gain exactly 3 will not reliably start; it must exceed 3 initially. (3) Positive feedback does not mean instability; negative feedback keeps the gain controlled.

5. Equations and Derivation

Series arm Zs = R + 1/(sC); parallel arm Zp = R/(1 + sRC) (R₁=R₂=R, C₁=C₂=C).

β(s) = Zp/(Zs + Zp) = sRC / [1 + 3sRC + (sRC)²]
β(jω) = jωRC / [(1 − ω²R²C²) + j3ωRC]

The phase is zero when the real part of the denominator vanishes: 1 − ω²R²C² = 0.

ω0 = 1/(RC)  ⇒  f0 = 1/(2πRC)  (Hz, with R in Ω and C in F)
β(jω0) = j/(j3) = 1/3 ∠0°
Barkhausen: Aβ = 1 ⇒ A = 3  ⇒  1 + Rf/Rg = 3 ⇒ Rf = 2Rg
Unequal components (series R₁C₁, parallel R₂C₂): f0 = 1/(2π√(R₁R₂C₁C₂)); Amin = 1 + R₁/R₂ + C₂/C₁
|β| = x / √[(1 − x²)² + 9x²], x = f/f0; phase = 90° − tan⁻¹[3x/(1 − x²)]

Limiting cases: x → 0: β → jx (lead, +90°); x → ∞: β → −j/x (magnitude 1/x, lag, −90°). Decibels: 20 log(1/3) = −9.54 dB; the amplifier must supply +9.54 dB. Variables: R in Ω, C in F, f in Hz, ω in rad/s.

6. Solved Numerical Problems

Problem 1 (Easy)

Given: R = 10 kΩ, C = 10 nF. Find: f₀. Formula: f₀ = 1/(2πRC).

f₀ = 1/(2π × 10×10³ × 10×10⁻⁹) = 1/(6.283×10⁻⁴) = 1.59 kHz. Interpretation: a mid-audio tone.

Problem 2 (Moderate, design)

Given: f₀ = 1 kHz, C = 0.1 µF, Rg = 10 kΩ. Find: R and Rf.

R = 1/(2π × 1000 × 10⁻⁷) = 1/(6.283×10⁻⁴) = 1.59 kΩ (use 1.6 kΩ). Rf = 2Rg = 20 kΩ; in practice use ~22 kΩ (or a pot) so A is slightly above 3 plus AGC. Interpretation: gain must be marginally above 3 for startup.

Problem 3 (GATE-style, Difficult)

Given: series R₁ = 10 kΩ with C₁ = 10 nF, parallel R₂ = 20 kΩ with C₂ = 10 nF. Find: f₀ and minimum amplifier gain.

f₀ = 1/(2π√(10k × 20k × 10n × 10n)) = 1/(2π × 10⁻⁸ × 14142) = 1/(8.886×10⁻⁴) = 1.125 kHz. Amin = 1 + R₁/R₂ + C₂/C₁ = 1 + 0.5 + 1 = 2.5, so Rf/Rg = 1.5. Shortcut: with equal C, Amin = 2 + R₁/R₂.

8. Core Electronics Interview Questions

Industry perspective: Wien bridge stages appear in audio analyzers, calibration sources and sensor-excitation circuits. Engineers verify startup, THD and amplitude stability across temperature and supply, usually in SPICE/Multisim first, then on the bench with an oscilloscope and spectrum analyzer.
